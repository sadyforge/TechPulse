# 🔐 Authentication App

A modern and secure authentication application built with **Next.js** and **Better Auth**. This project provides a clean authentication experience with user registration, login, password validation, and password visibility controls.

## ✨ Features

* 🔑 User registration with email and password
* 🔐 Secure user login
* 👁️ Show/Hide password functionality
* ✅ Password validation

  * Minimum 8 characters
  * At least one uppercase letter
  * At least one number
* 🚪 User logout functionality
* 📱 Responsive and clean UI
* ⚡ Built with Next.js
* 🛡️ Authentication powered by Better Auth

## 🛠️ Technologies Used

* Next.js
* React
* TypeScript / JavaScript
* Better Auth
* Tailwind CSS
* React Aria Components

## 🎯 Purpose

This project was created to practice and understand modern authentication workflows in Next.js, including user registration, login, validation, session handling, and protected authentication features.
